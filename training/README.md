# LocalStoryChat Training

## Purpose

This directory contains reusable writer-style training material for LocalStoryChat.

The training material is separate from each novel's canon and story state.

## Layout

- core/ reusable writing behaviors
- gold/ polished examples that represent the desired writing quality
- story_examples/ examples that demonstrate story-specific continuity or knowledge boundaries
- writer_style.md master style reference
- core_dataset.jsonl generated from the reusable core examples

Backups and temporary generated files do not need to be committed.

## Guiding principle

The trained writer should learn how to write. Novel-specific facts should continue to live in the story JSON and state system.
