## What this repository contains

This repository remains the existing **LocalStoryChat v7** project: a local browser chat interface built around the llama.cpp / `llama-cli --simple-io` workflow. Its existing story-oriented behavior and files are preserved.

This is not the StoryBuilder Writer App, not the separate Story Bible App, and not the planned future general-purpose Local Model Chat application.

## Existing launch

Run from the local repository:

```bash
cd ~/Documents/LocalStoryChat
./start.sh
```

Existing desktop installer:

```bash
cd ~/Documents/LocalStoryChat
./install_desktop.sh
```
